E221 弹幕 ASS 解析加固 真机证据（emulator Pixel_Tablet + JVM，2026-10-25）
================================================================

本批为解析层加固，验证以 JVM 单测为主 + 模拟器空结果日志冒烟。
装机：`adb -s emulator-5554 install -r app/build/outputs/apk/release/app-release.apk`。

----------------------------------------------------------------
1. 改动
----------------------------------------------------------------
- **Format/Dialogue 只认 `[Events]` 节**：按节头行（`[…]`）切换当前节——此前
  任何位置的 `Format:`/`Dialogue:` 都会被认，样式节里恰好带 Start/Text 字样
  的 Format 行会污染字段序（本次用「样式节放陷阱 Format 行」的最小文件钉住）。
- **`Comment:` 事件行显式跳过并计数**（此前静默落空）。
- **`\move(x1,y1,…)` 的起始 y 参与顶/底判定**（与 `\pos` 同口径拿纵坐标与
  PlayResY 中线比）——此前 \move 行一律兜底滚动，顶部飘过的移动弹幕挂错车道。
- **空结果给原因**：新增 `parseAssDetailed` 返回统计（dialogues/comments/
  droppedTimestamp/droppedFieldMismatch/emptyReason），`parseAss` 委托之
  （原签名不变）；`loadFileSource` 在 ASS 候选解析为 0 条且有 Dialogue 行时，
  把原因写 logcat（`DanmakuSource` 标签，uri 带出便于多候选分辨）。
  「段数不一致丢整行」既有行为由用例钉住。
- UI 层（菜单/空态）不展示原因——当前空结果会自然落到下一候选或无来源，
  原因仅供排障（logcat），记为边界。

----------------------------------------------------------------
2. 测试与门禁
----------------------------------------------------------------
- 新增 `DanmakuAssHardeningTest` 5 项：样式节 Format 不污染字段序 /
  Comment 跳过并计数 / \move 起始 y 顶底判定（y<中线=顶、y>中线=底）/
  段数不一致丢整行 / 时间戳全坏 0 条且原因含「时间戳无效」。
- 门禁（最终源码全跑）：test **150 套件 / 1043 项 / 0 失败**（基线
  149/1038 + 5 项）、lint 15 份 0 issue、release 29,208,295 B、
  debug 66,222,573 B（纯解析层，dex 桶内吸收）。

----------------------------------------------------------------
3. 真机（模拟器）冒烟
----------------------------------------------------------------
- 装机正常、播放/挂载通路无回归（本批不改渲染/加载行为，仅解析统计与
  \move 判型）；
- 空 ASS 原因日志路径在真机触发需要「有 Dialogue 行但全被丢」的文件——
  以单测口径覆盖（`DanmakuAssHardeningTest.空结果给出原因`），真机 logcat
  断言未单独采（构造多候选坏文件收益低），记为边界。

----------------------------------------------------------------
4. 边界
----------------------------------------------------------------
- \move 仍按「起始 y 判型后走滚动/顶/底车道」的弹幕化处理——不做真正的
  轨迹跟随（\move 的动画语义超出弹幕车道模型，维持既有口径）。
- 空结果原因只进 logcat；接 UI（播放选项弹幕区副标题等）需菜单改动，
  未做。
- 解析统计是逐行同步计数，十万行文件的额外开销为几个 Int 自增（可忽略，
  未单独测）。
