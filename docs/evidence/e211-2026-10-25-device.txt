4. Auto Backup 执行
----------------------------------------------------------------
- 设备默认备份管理器关闭、当前 transport 为 GMS（无账号 → Transport error）。
- 临时切到本地 transport 验证规则可解析（测试后恢复原状）：
  adb shell bmgr transport com.android.localtransport/.LocalTransport
  adb shell bmgr enable true
  adb shell bmgr backupnow com.noneplayer.app
  → Package com.noneplayer.app ... result: Success（约 474 KB）
  adb shell bmgr enable false
  adb shell bmgr transport com.google.android.gms/.backup.BackupTransportService
- 说明：本地 transport 的备份数据不可读（无 root），**未逐文件核对排除结果**；
  排除口径由 XML + lint + 单测（恢复后目录为空）覆盖。

5. 边界
----------------------------------------------------------------
- 未在第二台设备上走真实恢复（无可用 AOSP/备用机）；「恢复后空态 + 重新授权」

  迁移会指向错误媒体）；这是有意取舍，不是遗漏。
