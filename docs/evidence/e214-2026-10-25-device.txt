----------------------------------------------------------------
1. 改动
----------------------------------------------------------------
- 新增 `StageLockTier { None, Half, Full }`（rememberSaveable）：两档锁定互斥，
  转移收成枚举上的纯函数（onBadgeTap / onLockKey / onHalfLockMenu），单测钉住。
- 半锁（D3 裁定「只护画面」）：舞台手势动作（双击 seek / 长按倍速 / 横滑 seek /
  竖滑亮度音量）全部停用，点按唤控制层保留；控制层、返回键、键盘全部可用；
  解锁钮**常驻**（不随控制层自动隐藏）。
- 入口：全屏 fsMenu「更多」新增「半锁（只护画面）」行；竖屏「播放选项」网格在
  「锁定横屏」旁新增「半锁」tile（已半锁时变「解除半锁」）。右栏内嵌播放器
  无舞台手势，不渲染该行（不给假入口）。
- 整页锁（旧 stageLocked 布尔）语义零变化；键盘 `L`：未锁→整页锁、半锁→升级
  整页锁、整页锁→解锁。徽标点按：未锁→整页锁（不变）、任一锁定态→解除。
- 进入半锁的说明 toast 放在两个菜单入口回调里（放 LaunchedEffect 会随旋转/
  恢复的重组重跑而重复弹出）。

- fs-06：等待自动隐藏（>3.5s）后，顶/底控制层隐去，**解锁徽标仍常驻右侧中部**

- 手势屏蔽（暂停态 A/B：PAUSED 时 position 冻结，任何 seek 都会改变它）：
  * 双击右侧分区（2000,900）×2 → position 389860ms 不变（解锁时双击 = +10s）；
  * 横滑 900→2400px（≈满幅 seek 量程的大半）→ position 389860ms 不变。
  播放中对照：同手势在未锁定时正常推进（PLAYING 期间位置随墙钟前进）。
- fs-07：半锁暂停态控制层完整（顶栏/底栏/中央继续钮/徽标）——控制层可用。
- fs-08：半锁下按 BACK → 退出播放页回到媒体库（右栏内嵌续播）——**返回仍可用**，
  整页锁的 BackHandler 吞返回未扩大到半锁。
- fs-09→fs-10：重进播放页，菜单再进半锁（暂停态，控制层不自动隐藏）。
- fs-11：半锁下按 `L`（keyevent 40）→ 升级**整页锁**：顶/底控制层消失、
  中央继续钮消失，屏幕只剩右侧解锁徽标——整页锁语义零回归。
- fs-12：整页锁下按 BACK → 画面不变（返回被吞，解锁钮是唯一出口）——既有语义。
- fs-13：点解锁徽标 → 解除整页锁，控制层与中央继续钮恢复。

----------------------------------------------------------------
4. 边界
----------------------------------------------------------------
- 徽标常驻在竖屏形态未单独取证（竖屏暂停态控制层不自动隐藏，常驻无从观察；
  机制与全屏同一条 visible 公式 `(controlsVisible || stageHalfLocked) && !inPipMode`）。
- toast 只在菜单入口触发；键盘 L 从半锁升级整页锁无 toast（控制层闪现即反馈），
  与整页锁既有口径一致。
- 进程被杀后经 rememberSaveable 恢复进半锁/整页锁时不再弹 toast（控制层亮起仍会
  发生，与整页锁既有恢复行为相同）。
- 右栏内嵌播放器（类 PC 形态）的 `locked` 是它自己的整页锁，D3 未涉及，未改。
