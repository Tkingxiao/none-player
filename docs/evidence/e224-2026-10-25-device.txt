E224 屏蔽词对内嵌通路同口径 真机证据（JVM 单测为主 + 模拟器冒烟，2026-10-25）
================================================================

本批修一个真缺口：屏蔽词此前只过滤**文件**通路（`parseDanmakuFile` 的
filter），**内嵌** cue 通路直接 spawn 绕过了屏蔽词——同一份屏蔽词表在两条
通路口径不一致（任务 §5「屏蔽词对文件与内嵌同时生效」的后半句）。
装机：`adb install -r app/build/outputs/apk/release/app-release.apk`
（E224 构建，模拟器）。

----------------------------------------------------------------
1. 改动
----------------------------------------------------------------
- `Danmaku.kt`：新增 `embeddedCueDecision(text, lastText, blocklist)` 纯函数
  三态决策（Spawn / SkipDuplicate / SkipBlocked）——屏蔽词命中即 Skip，
  与文件通路的 `DanmakuBlocklist.isBlocked` 同一实现；空文本与重复文本按
  既有语义跳过（空文本不更新 lastText）。
- `DanmakuOverlay` 内嵌 cue 收集器改走该决策：
  * SkipBlocked 记 lastText（同一条被屏蔽文本不重复过筛；紧随其后的不同
    cue 正常放行）；
  * 倒退 seek（E223）先清表——与决策正交（先清后按新表 spawn）；
  * SkipDuplicate 不动 lastText（既有语义保留）。

----------------------------------------------------------------
2. 测试与门禁
----------------------------------------------------------------
- 新增 `DanmakuEmbeddedCueDecisionTest` 5 项：正常放行 / 重复与空文本跳过 /
  屏蔽词命中（含大小写不敏感）/ 屏蔽后不吞下一条不同 cue / 空屏蔽词表
  永不屏蔽。
- 门禁（最终源码全跑）：test **152 套件 / 1055 项 / 0 失败**（基线
  151/1050 + 5 项）、lint 15 份 0 issue、release 29,208,295 B、
  debug 66,222,573 B（桶内吸收）。

----------------------------------------------------------------
3. 真机（模拟器）冒烟
----------------------------------------------------------------
- E224 构建装机后内嵌/文件两条弹幕通路加载无回归；
- 内嵌轨屏蔽词的端到端可见行为需要内嵌弹幕轨片源（§9.6 素材欠账，同
  E223 边界）——决策语义以单测口径覆盖，真机断言未单独采。

----------------------------------------------------------------
4. 边界
----------------------------------------------------------------
- 屏蔽词命中在 UI 上无提示（不弹 toast 不计数）——与文件通路静默过滤
  同口径；如需「已屏蔽 N 条」反馈另立任务。
- 倒退 seek 清表与屏蔽词决策正交（先清后决策），组合行为由
  DanmakuBoundedReadTest + 本测试分别钉住。
